# v0.7.9-preview

修复设备钢平台直接建模时“没有最终答复、没有写入模型”和错误归因到基础偏移的问题。

- 轴网识别兼容 `K-H×16-17`、`K-Hx16-17` 和带“轴”后缀的常用表达。
- AI 返回截断、残缺或不可解析的协议 JSON 时，宿主自动要求重新输出简短且完整的执行计划。
- 设备平台输入校验改为逐字段报告，直接标明无效的尺寸、高度、板厚、基础偏移、分跨或次梁间距。
- 明确允许 `foundationOffsetMm=0`；设备平台顶高必须大于侧平台顶高，避免同高梁重复创建。
- 系统提示要求 `reply` 保持简短，已经存在于 `plan` 的参数不再重复输出，降低长响应被截断的概率。
- 增加自动检查，覆盖乘号轴网解析、相同平台顶高校验和截断 JSON 恢复。

直接建模仍会先在 Revit 事务中试建并回滚检查，检查通过后自动正式提交；这不是结构计算或施工图审查。
