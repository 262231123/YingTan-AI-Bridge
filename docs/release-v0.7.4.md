# v0.7.4-preview

本版改善 Revit 对话助手的入口可见性和面板初始化错误反馈。

- 新增原创 BIM 建筑线框 + AI 节点图标，透明背景，无文字及第三方商标。
- 母版作为 DLL 嵌入资源，运行时分别解码为 Revit 功能区需要的 32×32 与 16×16 图像。
- 在 Revit 内置 `Add-Ins` 选项卡创建“盈碳 AI 助手”面板。
- “AI 助手”作为独立大按钮显示；“使用帮助”和“关于软件”收纳为相邻小按钮。
- 点击入口时若停靠面板未完成初始化，会显示明确错误并引导查看 `bridge.log`。
- `.addin` 中的 ExternalCommand 备用入口保持不变，可从 `Add-Ins → External Tools` 启动。

安装后需要完全退出并重新启动 Revit，功能区资源和停靠面板才会重新加载。
