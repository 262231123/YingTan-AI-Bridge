# v0.6.0-preview — 轴网识别与设备钢平台建模

新增轴网与链接坐标识别、结构类型查询、三种分跨概念方案、钢柱/梁/平台板创建，以及对应内置 Skill。聊天自动读取 K-H轴/36-37轴这类请求的真实轴距；保留原始设计条件和同文档查询结果，支持补充信息后继续选择方案。

新增“自动创建设备平台（试建通过后执行）”选项，默认关闭，仅授权单个平台操作。提交前使用真实族试建、核对顶面高度并回滚；失效方案或几何错误不会成为可执行计划。

本版只做几何概念方案，不进行结构承载力或最小梁高优化求解；不含基础、支撑、节点、楼梯栏杆。必须在项目副本中试用，并由结构工程师验算后方可用于施工。

本地插件与回归项目编译成功；便携测试由 GitHub CI 执行，本机应用程序控制策略阻止测试程序运行。尚未完成真实 Revit/AI 端到端与安装器交互验收。

EXE包含本机构建的 Revit 2026.5（26.5.0.55 / .NET 10）和 AutoCAD 2024 组件。其他Revit小版本未验证。安装包未签名。MIT许可证。
