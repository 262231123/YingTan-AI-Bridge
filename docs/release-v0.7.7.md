# v0.7.7-preview

将直接创建从钢平台专用能力扩展为全局对话建模模式。

- 任意写入计划在必要模型查询完成、内部事务试运行通过后自动正式提交。
- 面板不再显示黄色“待执行计划”，也不要求用户再点“执行计划”。
- 钢平台的 `preview_steel_platform` 在全局直接模式下会被宿主拦截，改为 `create_steel_platform_direct`。
- 可在 `配置 → Agent` 随时关闭“全局直接建模”，恢复先审阅计划再执行。
- 事务回滚、文档会话令牌、失败中止、提交后构件回读和操作明细仍然保留。
- 任意 AI 生成的 C# 脚本仍需源码审阅，不会因直接模式而绕过安全边界。
