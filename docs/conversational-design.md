# 对话式设计 Agent（0.5.0 预览版）

现在可直接描述设计或操作需求。插件读取当前文档、视图、选择集、标高和墙类型，再连续执行必要的查询；条件明确后显示可审阅的写入计划。点击“执行计划”提交，随后回读返回的构件 ID 并解释结果。

## 可以直接尝试

- 在 Revit 中选中几面墙，输入：“把 @选择集 的注释改为‘待复核’，先检查参数是否可写。”
- “在当前层内部坐标 X=10000、Y=10000 mm 创建宽6000、深4000、高3000 mm 的矩形会议室，使用项目里200 mm的基本墙类型；如有多个匹配类型先让我选择。”宽深为墙中心线尺寸。
- “查看模型警告，先列出前20条，再定位我指定的构件。”
- “查找当前层的门，统计数量并检查我指定门的参数。”
- 第一阶段创建墙后，下一条消息可要求查询刚建墙的 ID、选择门族、在指定墙上放门。

矩形围合命令创建四面墙和一个房间，不含门窗、楼板或家具；模型已有房间或边界可能影响结果。一般墙、门窗、房间、参数修改和图纸操作仍受原生命令支持范围限制。完整建筑方案、任意曲面、自动规范认证等未实现。

## 本版执行行为

1. 从 Revit API 读取实时上下文；发送给用户已配置的模型服务。上下文包含模型标题、构件名称/ID、选择集和类型信息；按任务继续查询参数。
2. 每轮最多8步规划，每计划最多40项操作；最多3次错误反馈。查询结果持续提供给 AI，几何和事务仍由 Revit 验证。
3. 所有生成计划先参数预检。批次中任何失败会阻止进入待执行状态，AI 可根据真实错误修正。
4. 写入计划绑定当前打开的文档会话。新需求替换旧计划；重启后旧计划失效；切换文档会拒绝执行。执行前仍应审阅目标与数值。
5. 点击执行后提交原子批次，遵循现有“写入前确认”设置。计划从待执行列表移除，避免重复点击。失败或回滚不会被标记为成功。
6. 根据写入结果中的构件 ID 回读（最多40个），随后进入只读核验阶段；无返回 ID 或分页/截断时不能视为全量验证。核验失败会保留已经返回的执行事实。
7. “停止”取消 AI 与尚未派发的请求；已经进入 Revit 的事务等待其完成或回滚，不会因等待超时重发写操作。

脚本工作室仍保留在明确要求“生成脚本/代码/Dynamo”的请求中。关键词扫描不是代码沙箱；生成文件不会自动执行。精装插件的外部面板动作暂不加入自动对话循环，原有桥接接口保留。

## 竞品调研与本版取舍（2026-09-08）

没有公开的统一测试可以证明某一个产品“最好”。本次参考官方公开功能与使用说明，未进行竞品付费版实测，也未复制第三方代码。

| 参考产品 | 官方公开能力 | 本版采用的方向 |
| --- | --- | --- |
| [ArchiLabs](https://archilabs.ai/architecture-engineering) | 对话组织图纸、标记、参数等自动化；引导输入与复用工作流 | 连续读取依赖、分阶段实施设计；本版未实现其全部出图/标记能力 |
| [BIMLOGIQ Copilot](https://apps.autodesk.com/RVT/en/Detail/HelpDoc?appId=1840006799718333764&appLang=en&os=Win64) | 自然语言命令、@构件引用、连续对话与保存命令 | @选择集上下文和后续修改；本版尚无可复用命令库或完整@自动补全 |

本版集中解决旧流程在查询后结束、错误预检被误标成功、宿主版本写死2027等问题。新加的3个内置工作流 Skill 是“对话式设计执行”“选择集连续编辑”“实时警告核查”，底层对应真实原生命令。

## 验证与安装基线

执行 `dotnet run --project tests/AgentChecks -c Release` 可运行无需 Revit 的回归检查，覆盖连续查询、失败反馈、命令限制、文档标识、取消、只读核验和结果 ID 回读。

本机安装的是 Revit 2026.5（26.5.0.55），其 `RevitAPI.runtimeconfig.json` 声明 .NET 10。本版安装包按这个 SDK 构建，包含 Revit 2026 与 AutoCAD 2024 载荷；不据此承诺其他 Revit 2026 小版本或其他年份兼容。

已做构建与模拟回归检查；本轮未启动 Revit 或使用实际模型服务执行端到端建模，也未完成 EXE 安装交互验收。首次试用请在项目副本验证参数编辑、矩形房间创建及撤销。
