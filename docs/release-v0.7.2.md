# v0.7.2-preview

本版重点补齐 Revit 命令执行结果的可追溯性，并统一模型写入的确认入口。

## 处理记录

- 聊天面板底部状态栏现在可以点击。
- 新窗口按时间显示本次 Revit 会话最近 200 条命令，包括命令名、模型、成功/失败和耗时。
- 选中记录后可查看格式化返回 JSON；异常记录显示具体异常类型、消息和调用信息。
- 支持复制当前明细以及直接打开 `%LOCALAPPDATA%\RevitCodexBridge\bridge.log`。
- `run_batch` 返回 `failures > 0`、`ok: false`、`succeeded: false` 或回滚状态时，即使没有抛出顶层异常，也会正确计入失败。

## 写入确认

- 移除聊天框下方“自动创建设备平台（试建通过后执行）”选项。
- 设备平台与其他建模修改一样，在试建通过后进入待执行计划，由用户点击“执行计划”后提交。
- 保留设置中的普通写入确认策略；脚本源码审阅规则不变。

处理记录只保存在当前 Revit 进程内；重启后的历史请查看完整日志文件。
